Like Misaka Mikoto sending a railgun through the network — I'm learning to navigate every packet, every protocol, every signal.

- ⚡ **Core Topics** : TCP/IP, DNS, subnetting, routing
- 🔐 **Security** : Ethical hacking mindset, defense strategies
- 📡 **Tools Exploring** : Wireshark, nmap, iptables, Netcat
- 🛡️ **Approach** : Think like an attacker, defend like a guardian

- 🔭 **Vision** : Understanding the invisible infrastructure of the world
